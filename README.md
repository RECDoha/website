# Rifqa Education Centre (REC) Website

Marketing website for **Rifqa Education Centre**, a British Curriculum tuition centre in Doha, Qatar offering English, Maths & Sciences for Years 1–13.

## Pages

| File | Description |
|---|---|
| `index.html` | Home page |
| `about.html` | About the centre |
| `syllabi.html` | Overview of curricula offered |
| `cambridge.html` | Cambridge curriculum details |
| `edexcel.html` | Edexcel curriculum details |
| `events.html` | Centre events (awards, spelling bee, sports day, etc.) |
| `testimonials.html` | Student/parent testimonials |
| `faq.html` | Frequently asked questions |
| `contact.html` | Contact information |
| `register.html` | Assessment/lesson booking form |
| `_mobiletest.html` | Mobile layout test page |

## Structure

```
Website/
├── assets/
│   ├── css/style.css   # shared stylesheet
│   └── images/         # site imagery
├── *.html               # site pages
```

## Tech

Static HTML/CSS site — no build step or dependencies. Open any `.html` file directly in a browser, or serve the folder with any static file server.
